Welch Labs–style technical explainer series for the Logos stack. One hard idea per episode, built from first principles, with the math on screen and Logos appearing only as the concrete instantiation.

## Series conventions

- One physical prop that *is* the episode (metronome table, two jars, burned shards)
- One runnable simulation per episode
- Math shown in full for 2–3 objects max; everything deeper is linked, not shown
- Logos named in the final act only; earlier acts stand alone as generic explainers
- Every technical simplification gets Vac reviewer sign-off before animation
- Recurring motif: the stake-threshold lottery equation, animated identically in ep. 01 (public) and ep. 02 (in the dark)

## Episode lifecycle

treatment → script → technical review → storyboard → animation → edit → release
