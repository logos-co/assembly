We create and publish content in a myriad of places. This document aims at identifying all of them so that the org can identify where things are and how best to move forward on a unified front. 

The general flow of creating content is as follows:
1. Coordinate around what content should be made, who's responsible for making it, when to do it, where it should live, and how it should be presented to various audiences. 
2. Create the content
3. Store that created content somewhere
4. Share that content and make it discoverable for various audiences
