`Claire` from the infra-bi team created an aggregator and static site generator after watching the Townhalls. 
- Static Site Front-end: https://news.free.technology
- Github Repo: https://github.com/status-im/ift-weekly-news

It aggregates all new posts across various distribution resources you publish to and generates a static summary page each week (on Wednesday). On the first of each month, it will create the respective monthly summary.
