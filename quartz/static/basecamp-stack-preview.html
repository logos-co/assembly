How Logos Basecamp works.

The Logos stack is layered: the Logos Runtime at the foundation, the network on top, modules stacked above.

Apps

Basecamp is a dynamic interface for applications built on the private, decentralised internet. It ships with the Package Manager; 17 more apps install from the default catalog.

Modules

Modules deliver the functionality of the Logos stack: private storage, messaging, blockchain, and wallets for LEZ, Ethereum and Monero. The package manager installs them, and each one loads when an app that needs it opens.

Runtime

At its core is a lightweight runtime that manages self-contained modules. It loads them, tracks their state, and issues the capability token that every call between modules carries.
