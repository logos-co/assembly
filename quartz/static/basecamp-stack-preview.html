The Logos stack reads bottom-up: runtime at the foundation, network on top, modules exposing capability, protocols composing those into something useful, applications at the apex. Each layer is narrower than the one below it, because each one chooses from what's beneath. The question is then: how do users and developers actually reach into this stack? Three entry points at the top answer that.

Full stack at a glance

overview Three ways into the same stack. Basecamp is the default launcher: install it, get a unified UI that surfaces whatever modules you have. A Standalone App bundles a custom UI with just the modules it needs and ships as a single binary. A Headless Node skips the UI entirely and drives the core directly. Pick a use case above to see — with live flow arrows — which slice each one touches.

The arrows are the point: a chat user's bytes flow through Chat → Delivery → P2P, never touching the blockchain. A DEX trader's flow through LEZ → Blockchain, never touching Storage. A validator bypasses everything above the module layer. Same stack, different cross-sections — that's the composability pitch.
