The Logos stack reads bottom-up: runtime at the foundation, network on top, modules stacked above (vertically higher modules depend on those beneath them, implicitly composing into something useful), and app backends at the apex. Each layer is narrower than the one below it, because each one chooses from what's beneath. Three entry points at the top answer the question of how you actually reach into the stack.

Full stack at a glance

overview Three ways into the same stack. Basecamp is the default launcher: install it, get a unified UI that surfaces whatever modules you have. A Standalone App bundles a custom UI with just the modules it needs and ships as a single binary. A Headless Node skips the UI entirely and drives the core directly. Pick a use case above to see — with live flow arrows — which slice each one touches.

The arrows are the point: a chat user's bytes flow through Chat → Delivery → P2P, never touching the blockchain. A DEX trader's flow through LEZ → Blockchain, never touching Storage. A headless validator bypasses the App Backends layer and reaches into modules at whatever depth the role demands. Same stack, different cross-sections — that's the composability pitch.
